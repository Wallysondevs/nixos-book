# Prefácio {#preface}

Este manual descreve como instalar, usar e estender o NixOS, uma distribuição Linux baseada no sistema de gerenciamento de pacotes puramente funcional [Nix](https://nixos.org/nix), que é composto usando módulos e pacotes definidos no projeto [Nixpkgs](https://nixos.org/nixpkgs).

Informações adicionais sobre o gerenciador de pacotes Nix e o projeto Nixpkgs podem ser encontradas, respectivamente, no [manual do Nix](https://nixos.org/nix/manual) e no [manual do Nixpkgs](https://nixos.org/nixpkgs/manual).

Se você encontrar problemas, por favor, relate-os no [`Discourse`](https://discourse.nixos.org), na [sala Matrix](https://matrix.to/#/%23nix:nixos.org), ou no canal [`#nixos` no Libera.Chat](irc://irc.libera.chat/#nixos). Alternativamente, considere [contribuir para este manual](#chap-contributing). Bugs devem ser relatados no [rastreador de issues do GitHub do NixOS](https://github.com/NixOS/nixpkgs/issues).

::: {.note}
Comandos prefixados com `#` devem ser executados como root, seja exigindo o login como usuário root ou alternando temporariamente para ele usando `sudo`, por exemplo.
:::
